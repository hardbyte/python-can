Added the ``listen_only`` argument and property to :class:`can.BusABC` and ``--listen-only`` to the CLI tools, deprecating the interface specific alternatives; ``send()`` on a listen-only bus now raises :class:`~can.exceptions.CanOperationError` on all built-in interfaces, and interfaces whose constructor does not declare ``listen_only`` reject ``listen_only=True`` with :class:`~can.exceptions.CanInterfaceNotImplementedError`.
